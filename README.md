# Застраховки 8 — мобилно приложение (PWA)

Ново, стабилно приложение за Бояна Аша (застраховка брокер).

## Философия
- **Excel е главен източник** за полици/клиенти/коли (`~/Documents/Zastrahovki8 Agent.xlsx`).
- **Приложението чете** данните от Excel (генерира се JSON при синхронизация).
- **От телефона се въвеждат само**: бележки (щети), адрес на пращане, прогрес/статус, ГТП/винетки.
- Тези допълнения се пазят в Google Sheets (облак), достъпни винаги.

## Технология
- Статичен HTML/JS/CSS (PWA) — работи като приложение на телефона
- Чете данни от: `data.json` (генериран от Excel) + Google Sheets (за бележки/адреси)
- Хостинг: GitHub Pages / Vercel (безплатно)

## Статуси
### Полица
1. Активна — днес между начало и край, вноските платени в срок
2. Предстоящо подновяване — ≤30 дни до изтичане
3. За контакт сега — ≤15 дни
4. Време е — ≤7 дни 🔴
5. Изтича днес — в деня на изтичане
6. Изтекла — датата минала, няма нова полица → видима 30 дни "за възстановяване"
7. Подновена/Активна — при нов номер на полица + нова крайна дата за същата кола

### Вноска (отделен флаг)
- Предстояща — 15 дни преди падеж
- Очаква плащане — 7 дни преди падеж
- Просрочена — в деня на падежа и след
- Платена — отбелязана

## Секции
- **Начален екран**: 🔍 търсене + 📅 предстоящи (всичко бъдещо, по дата)
- **Опашка за днес**: приоритетни контакти
- **Досие на кола**: марка/модел/рег/VIN, собственик, адрес, полици, вноски, ГТП/винетки, бележки, прогрес
- **Досие на клиент**: име, телефон, коли, полици, събития
- **Финанси**: от колона "Печалба" — колко изкарва
- **Генератор на оферта**: темплейт (Застр. сума / КАСКО еднократно / КАСКО вноски / ГО)
- **Калкулатор** комисион/отстъпка — Етап 2
